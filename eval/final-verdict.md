## Консенсус совета (все пятеро)
1. Блокер №1 — ручные шаги владельца: сертификат Apple Development ($99),
   ЗАТЕМ Screen Recording для bin/AudioCapture.app, затем restart-daemon.
   Порядок обязателен: грант до сертификата слетит при первой пересборке.
   Пока не сделано — записи mic-only (streak 9), комбайн питается половиной
   разговоров, а commitments-таблица в проде пуста (0 строк / 226 звонков).
2. Не строить UI поверх commitments, пока извлечение нестабильно
   (5→2→0 на одной сессии; recall 0/3). «Каждая поверхность над
   нестабильными данными — вежливо оформленная ложь» (Айв).
3. Загадка нестабильности разобрана до фактов:
   - гипотеза «раздутый промпт» СНЯТА (Суцкевер: templates.py побайтово
     идентичен между прогонами циклов 2 и 3);
   - Whisper дробит обещания на 2-4-словные строки — модель не видит
     цельной фразы (Суцкевер, проверено по calls.db);
   - action_items и commitments каннибализируют друг друга — одна и та же
     инструкция дважды; commitments — последнее поле длинной required-схемы,
     декодеру дешевле закрыть пустой массив (Карпати);
   - «мягкие» обещания («давайте синхронемся») не распознаются как
     обязательства.

## Приоритеты следующего этапа
1. Владелец: сертификат → Screen Recording → restart → один реальный
   двусторонний звонок до brief.py с непустым «должен: N» (Черный: это
   максимум пользы недели, единственная проверка, что циклы на что-то
   опираются).
2. «Один вопрос — один вызов» (Карпати): commitments — отдельный узкий
   LLM-вызов на чанк; action_items проецируются из них кодом. Убирает
   каннибализацию как класс.
3. Мощность измерений (Суцкевер): разметка 30-40 обещаний по всем golden-
   сессиям + K=5-10 повторов на сессию до любых новых выводов; тест
   гипотезы фрагментации — склейка соседних реплик спикера (3-5с) перед
   саммаризацией.
4. Repeat-and-vote на узком поле обязательств (стохастичность 14B —
   проектировать вокруг неё); сравнение с qwen3:32b на golden — дёшево.
5. После стабилизации: Swift-брифинг по человеку (заголовок из brief-модели),
   resummarize исторических звонков (наполнить таблицу), напоминания
   в почту (мандат), consent второй стороны (блокер публичности).
