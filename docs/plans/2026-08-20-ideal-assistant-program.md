# Ночная программа: идеальный помощник встреч (2026-08-20)

Мандат владельца (дословно, перед сном): «делаешь идеального помощника,
который понимает контекст встречи, готовит тебя к встрече и, как минимум,
фиксирует договорённости, а как максимум — куда это отправляется».
Схема: (1) дрим-тим + совет смотрят, как всё собрано; (2) собираю и тестирую;
(3) шесть циклов полировки. Владелец спит — все решения автономные,
ручных шагов не требовать, наружу ничего не отправлять (черновики — локально).

Стартовые условия: оба канала записываются (починено сегодня в ночь),
commitments нестабильны (5→2→0), brief.py CLI жив, календаря в продукте нет,
модель qwen3:14b локально, эвал-харнесс с golden set. Реальных двусторонних
записей: 2 тестовые от сегодня.

Фаза 1 — панели (параллельно):
- Дрим-тим (4 эксперта под задачу): дизайн помощника — контекст, подготовка,
  фиксация, маршрутизация.
- Совет директоров (5): оценка текущей сборки против цели.
Синтез → архитектура → план.

Фаза 2 — сборка и тесты (TDD):
- Ядро: узкий отдельный вызов для договорённостей (спека Карпати) +
  repeat-and-vote + склейка фрагментированных реплик (гипотеза Суцкевера).
- Контекст: meeting_context(session) — прошлые звонки с участниками,
  открытые обязательства; вплетается в саммари и бриф.
- Подготовка: бриф-уведомление в момент согласия на запись + post-call
  дайджест «к следующему разговору с X».
- Маршрутизация (максимум): локальные дайджесты ~/call-recorder/digests/ +
  генерация черновика письма ЛОКАЛЬНО (файл), отправка — только вручную
  владельцем; в почту сами не ходим (вердикт совета: не слать по
  недостоверным данным).
- Эвалы: recall-разметка по реальным записям, метрика стабильности
  (K-повторы), метрики брифа.

Фаза 3 — шесть циклов полировки: каждый = прогон эвалов (сокращённый) →
точечное ревью (2-3 директора ротацией, финал — полный совет) → правки.
Утром: отчёт владельцу + обновление памяти + landing.

Бюджетные правила ночи: коммиты без пуша; календарных и почтовых интеграций
наружу нет; демон не трогать во время реальных звонков (их не будет — ночь);
пересборка audio-capture запрещена без крайней нужды (TCC привязан к python,
но осторожность не отменяется).
