# Архитектура ночной сборки (синтез панелей)

Панели: Педрегал (продукт), Аллен (GTD), Вохра (доставка), IE-эксперт
(извлечение), экспресс-совет (5 линз). Полные отчёты — в истории сессии.

## Решения
1. Контекст = история отношений с человеком (brief.py) — подключить провода:
   cli brief, post-call уведомление с долгами. Календарь (EventKit) — решение
   владельца, не ночи. Угадывать собеседника до звонка — никогда.
2. Извлечение договорённостей v2 (src/commitments2.py):
   препроцессинг: склейка реплик одного спикера (пауза ≤1.0с, потолок 40 слов);
   стадия 1 — regex-кандидаты (коммиссивы, «давайте…», «сейчас скину»,
   модальные усилители); стадия 2 — узкий LLM-вызов на кандидата (окно ±1
   реплика, 3 прохода temp 0.25, консенсус ≥2/3); верификация цитаты кодом
   (exact → fuzzy 0.6/0.8); committer через _owner_attested. Единственный
   источник таблицы commitments.
3. Жизненный цикл (Аллен): status меняет только владелец; auto-закрытие —
   только кандидат с цитатой и подтверждением; resolution_source в схему;
   uncertain никогда не в счётчике «должен: N»; пустота = «не найдено — не
   значит не было»; без цитаты — не факт.
4. Доставка (Вохра): post-call followup .md ({session}-followup-{slug}.md,
   Договорились/Беру на себя/От тебя жду, хвост «сверь перед отправкой»);
   утренний дайджест по смене даты в демоне ({date}-morning.md, «горит»
   первым, включая без-дедлайна >7 дней); только файлы, Mail.app/mailto —
   после стабилизации; digests/ в .gitignore; уведомление после звонка
   упоминает черновик только если контент есть.
5. meeting_context(session): прошлые звонки + открытые обязательства
   участников → в пост-колл дайджест (в промпт саммари — после стабилизации).
6. Эвалы: разметка обещаний по июльским golden-сессиям (сегодняшние тестовые
   записи — казино-стрим, непригодны); self-consistency (цель ≥0.7) и CV по
   K=5 повторов; attributed recall.

## Порядок сборки: A merge_turns → B commitments2 → C провода в демон/таблицу
→ D lifecycle/brief honesty → E meeting_context → F digests/CLI → G эвалы →
6 циклов полировки (ревью на Fable, финал — полный совет).
